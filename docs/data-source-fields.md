# 数据源接口字段调研

三大免费行情源(东财 / 腾讯 / 新浪)各接口的**实测字段枚举**。样本:贵州茅台 `sh600519`、白酒板块 `BK0475`,数据日 2026-07-20(盘后)。值为真实返回,含义为对值解读得出(常见字段高置信,个别 f 号未标注)。探测脚本见 `tools/`(或 scratchpad `allapi.ps1` / `fields.ps1`)。

> ⚠️ **头号坑:东财字段号跟接口绑定,不能跨接口套用。** 例:`f127` 在 `clist` 里是"市净率",在 `stock/get` 里是"细分行业名"。

### 3. `push2.eastmoney.com/api/qt/ulist.np/get` — 批量行情(secids 逗号分隔,197 字段/只)

字段号 = clist 股票行那套。**关键:带 f100 行业 / f102 地区 / f103 概念** —— 腾讯批量没有、东财批量有。可用来在每秒行情里直接带出板块,省掉单独查。

**涨速/资金流也在这**(2026-07-23 盘中实测,A股专属):**f22 涨速** · f11 5分钟涨跌 ·
**f62 主力净流入(元)** · f66 超大单净 · f72 大单净 · f78 中单净 · f84 小单净 · f184 主力净占比%。
(f62/f66/f72/f78/f84 与 fflow/kline 当日行完全对得上。)

### 4. `push2his.eastmoney.com/api/qt/stock/kline/get` — 日/周/月 K(项目在用)
`klines` 每行 CSV:`日期,开,收,高,低,量,额,振幅%,涨跌幅%,涨跌额,换手%`。⚠️ 列序 **开-收-高-低**(收在第 3 位)。附 `preKPrice` 前收、`dktotal` 总条数。

⚠️ 两个"进行中的 K 线"的坑(2026-07-28 实测):
- **当日那根是没走完的**:盘中拉到的最后一根,收=当时价、高/低/量都只到此刻为止。收盘后才定稿(留 ~20 分钟给收盘竞价和落库)。缓存这根等于把半截数据钉住一整天,所以项目里**盘中直接砍掉当日那根**,收盘后才拉定稿值。
- **周/月线进行中的那一桶,日期标签会变**:标的是**该周期内最新交易日**,不是周五/月末。实测 `klt=102` 末三根 `2026-07-17, 2026-07-24, 2026-07-28`——07-28 是周二,即本周桶;周三再拉就变成 `07-29`。所以判"是不是当日那根"要比日期,不能按位置;同理任何增量拼接都得按日期切断,逐根按日期合并会让同一周留下两根。

### 5. `push2his.eastmoney.com/api/qt/stock/trends2/get` — 分时(项目在用)

### 6. `push2.eastmoney.com/api/qt/stock/details/get` — 逐笔成交
`details` 每行:`时间,成交价,量(手),笔数,方向`(1 买 / 2 卖 / 4 中性)。

### 7. `push2his.eastmoney.com/api/qt/stock/fflow/kline/get` — 资金流
`klines` 每行:`日期,主力净额,超大单净额,大单净额,中单净额,小单净额`(元)。

### 8. `searchapi.eastmoney.com/api/suggest/get` — 代码搜索联想
需 `token=D43BF722C8E33BDC906FB84D85E326E8`。每命中:`Code · Name · PinYin · SecurityTypeName(沪A) · MktNum 市场号 · QuoteID(1.600519) · Classify(AStock)`。

## 结论(对"板块/概念"需求)

1. **板块只有东财有;腾讯、新浪都是纯量价接口。**
2. **东财 `ulist.np` 批量行情自带 f100/f102/f103** —— 若用它替代腾讯做每秒轮询,行业/地区/概念随行情一起来,零额外请求。
3. **东财 `clist` 一接口三用**:`fs=b:BK****` 取成分股、`fs=m:90+t:3` 取全部概念板块(含领涨股/成分数),可做"点概念看成分股"。
4. **细分行业/完整概念**:单只 `stock/get`(f127/f128/f129)或批量 `ulist`(f100/f102/f103),后者更省。
5. 项目现状:合约列表已缓存 f100 行业 / f102 地区 / f103 概念(A股),概念已在行情页显示为"概念"列。
6. **板块目录已按交易日缓存**(`boards.json`):随合约每日全量拉一次,东财 `clist m:90+t:1/2/3`
   三类共约 1022 个(行业 496 / 概念 495 / 地区 31),每个存 `代码BK+名称+类型+成分数`。
   **无单独"细分板块"接口**——行业 t:2 已含二级(名字带 Ⅱ)/三级(带 Ⅲ),平铺同一列表,靠名字后缀区分。
