# QuoteView

一个覆盖**六大交易所**的 Windows 桌面行情终端 —— 沪A · 深A · 北交所 · 港股 · 美股 · 韩股。
合约查询、实时行情、K 线/分时图，外加一个能"隐蔽看盘"的桌面置顶迷你行情条。

> 行情数据来自第三方公开接口，仅供学习研究，**不构成任何投资建议**。

## ✨ 功能特色

- **六市场合约查询** —— 近 3 万条合约全量本地检索，支持编码 / 中文名 / 拼音（`600519` · `茅台` · `gzmt`），
  按板块、类型筛选，表头排序。
- **实时行情** —— 分组自选，1 秒批量刷新；**丰富字段可自由配置显示**：价格/成交量/成交额/市值/换手/量比/
  市盈市净、所属**行业 / 地区 / 概念**，以及 A 股**涨速 / 主力资金**（主力净流入、超大/大/中/小单）。
  齿轮打开列设置，勾选显隐、拖动排序；大数进位显示（311.01万），悬停看真实值。
- **五档盘口** —— 买卖各五档的价格与挂单量，横条按量比例，跟实时行情同频刷新（数据就在行情响应里，
  不额外发请求）；主界面常驻，简洁面板也能挂。
- **K 线 & 分时图** —— 日 / 周 / 月 K 线 + 当日分时，**全量历史一次拉齐**，自由缩放平移，
  MA5/10/20/60 均线、成交量副图、十字光标读数、前/不/后复权切换。
- **简洁面板（隐蔽看盘）** —— 桌面置顶的半透明迷你行情条，主窗口退居后台；
  可配行数 / 透明度 / 显示字段 / 涨跌配色 / 行距，还能挂一张当前合约的**分时缩略图**或**五档盘口**。
  全局快捷键操作，不用切窗口。
- **分组管理** —— 拖拽排序、导入 / 导出、列布局记忆，指定哪些分组进简洁面板轮播。
- **自动更新** —— 后台检查新版本，底部状态栏一键更新、自动重启（多源下载，国内优先）。
- **红涨绿跌**（A 股惯例，已过色盲校验），涨跌幅以**昨收**为基准。

## ⌨️ 全局快捷键

| 快捷键 | 作用 |
| --- | --- |
| `Win + Alt + End` | 主窗口 ⇄ 简洁面板 互切 |
| `Win + Alt + ← / →` | 上一个 / 下一个合约 |
| `Win + Alt + ↑ / ↓` | 面板变亮 / 变暗（直至隐形） |
| `Win + Alt + PageUp / PageDown` | 上一个 / 下一个分组 |
| `Win + Alt + Delete` | 面板图表循环：关 → 分时缩略图 → 五档盘口 |

## 🖱️ 简洁面板鼠标操作

| 操作 | 作用 |
| --- | --- |
| 滚轮上 / 下 | 上一个 / 下一个合约 |
| 左键拖动 | 移动面板位置 |
| 右键 | 菜单（设置、导航、还原主窗口） |

## 📦 安装与运行

**环境要求**：Windows 10/11 + [.NET 8 桌面运行时](https://dotnet.microsoft.com/download/dotnet/8.0)（Desktop Runtime, x64）。

**方式一 · 直接运行**：拿到 `QuoteView.exe`，双击即可（单文件，无需安装）。

**方式二 · 从源码构建**：

```bash
git clone https://github.com/pcguan/QuoteView.git
cd QuoteView
dotnet publish src/StockClient.App -c Release -r win-x64 --self-contained false -o dist
# 产物：dist/QuoteView.exe
```

首次启动会联网拉取各市场合约列表并按交易日缓存（`%APPDATA%\StockClient` 下），之后离线也能用缓存。

## 🖱️ 使用要点

- **合约查询**：选交易所 / 类型，或直接搜；双击某行打开它的 K 线图。
- **实时行情**：左侧建分组、加合约（输代码或名称都行），双击行开 K 线；勾选分组是否进简洁面板。
- **进入简洁面板**：主界面「简洁面板」按钮或 `Win+Alt+End`；面板右键有设置与导航菜单，
  拖动可移动位置，用托盘图标或右键菜单还原主窗口。

## 📊 数据来源

行情 / K 线 / 分时来自**东方财富、腾讯、新浪**的公开接口，多源互为兜底。仅用于个人学习，
请勿高频滥用或用于商业用途。
