# 关注池

`watchlist.csv`，三列：`code,name,tag`。空文件（只有表头）就是不跟踪任何标的，
`fetch_market.py` 会跳过这一步，简报里也不会出现「关注池」一节。

```csv
code,name,tag
SH600519,贵州茅台,白酒
SZ000651,格力电器,家电
```

- `code` 支持 `SH600519` / `600519.SH` / `600519`（纯数字按 6/5 开头判沪、其余判深）
- `name` 只用于对照，实际名称以行情返回为准
- `tag` 自定义分类，原样出现在简报里

改完下次运行自动生效，不需要改代码。
